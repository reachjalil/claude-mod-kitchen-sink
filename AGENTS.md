# Project guidance

This is an independent public educational repository. Keep examples understandable, dependency-free and based on documented extension APIs. Preserve the Cowork workflow-plugin / Claude Code UI-mod distinction. Never claim desktop acceptance from mock tests or static validation.

Do not add telemetry, automatic model calls, session messaging, broad permission overrides or real service credentials to examples. Use synthetic data. Run the focused local tests and native validator after changing the mod. Keep public work authored under the maintainer's configured identity without additional tool co-authorship.
