---
description: Turn synthetic notes into a small reviewable experiment card
argument-hint: [paste notes or attach the bundled sample]
---
Using the user's supplied notes ($ARGUMENTS), or the bundled examples/workshop-notes.md when accessible, produce a short experiment card with four fields: Goal, Smallest change, Observable result, and Next question. Cite which supplied detail supports the suggested experiment. If no source notes are available, ask for them; do not pretend to read files. Explain which part of this result came from this command's instructions. Return the card in the conversation. Write a file only if the user asks; do not send messages, connect services, spend, or change records. This command needs no custom UI or connector.
